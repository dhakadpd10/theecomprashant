## The experiment: named viewer against a general opener (moved onto explainers)
- **Question:** does opening on who the reel is for and where they are earn more sends than the same reel with a general opening?
- **Why:** the only hit named its viewer and place in the first line. It also had #11 and a list, so this isolates the opener.
- **Setup:** 3 matched pairs, all at 09:00 IST (03:30 UTC).
  - **Pair 1, tutorial:** A opens on homemakers at home. B has no named viewer.
  - **Pair 2, prompt:** A opens on 9-to-5ers after office hours. B has no named viewer.
  - **Pair 3, explain:** A opens on people between jobs. B has no named viewer.
- **Matching rules:**
  - Pick each pair's topic from docs/EXPLAINER.md.
  - Within a pair, only the opening line and the first card differ. Keep everything else identical: hook id, analogy, diagrams, result, catch, caption, send line, end card and keyword.
  - Money-angle topics use only real platforms from docs/MONEY.md.
- **Carry-over rule:**
  - If pair 1 A already went out on 4 Nov as a money #11 list under the 3 Nov plan, post its B arm in that same format on 5 Nov so the pair stays matched.
  - Then run pairs 2 and 3 as explainers.
- **Order:**
  - Pair 1: A, then B the next day.
  - Pair 2: B, then A the next day.
  - Pair 3: A, then B the next day.
  - Start on 4 Nov if pair 1 A has posted. Otherwise start on 5 Nov and shift every date by one day. Pair 3 may finish next week.
- **Sequencing:** on experiment days, the 13:00 reel must be a different kind and use a different hook id, so neither repeat rule breaks.
- **Logging:** log `arm` (A or B) and `pair` (1, 2, 3) as columns.
- **Judge at 72 hours, in this order:**
  1. Sends per 1k reach, hand-checked to exclude Prashant
  2. Saves per 1k reach
  3. Outlier multiple against the explainer-era median, or the money-era median until that exists
  - Copy hold@3s and average watch time as diagnostics. They explain the result; they don't decide it.
- **Reading the result:**
  - Sends decide each pair. If both arms have 0 sends, saves decide. If both are also 0, the pair is a tie.
  - An arm wins if it takes at least 2 of the 3 pairs.
  - If a reel has under 20 reach at 24 hours, check it for a publishing fault. A confirmed fault voids the pair; it is not a loss.
  - Never fall back to views.
  - With 3 pairs this is directional only. If A wins, make the named-viewer opener the default next week and repeat the test before calling it a rule.
