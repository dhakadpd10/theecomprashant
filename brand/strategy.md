## The experiment: named viewer against a general opener
- **Question:** does opening on who the list is for and where they are earn more sends than the same list with a general opening?
- **Why:** the only hit named its viewer and place in the first line. If the #11 list itself did the work, both arms will land close together.
- **Setup:** 6 reels in 3 matched pairs, all #11, all at 09:00 IST (03:30 UTC).
  - **Pair 1, SITES (Get paid):** A opens on homemakers at home. B uses the same ways with no named viewer.
  - **Pair 2, SKILL (Earn with a skill):** A opens on 9-to-5ers after office hours. B uses the same list with no named viewer.
  - **Pair 3, MONEY (The prompt):** A opens on people between jobs. B uses the same prompt with no named viewer.
  - Only the opening line and the first card differ. Keep the list, favourite, screenshot card, catch, caption, send line, end card and keyword identical. Use only real platforms from docs/MONEY.md.
  - **Order:** pair 1 A on 4 Nov, B on 5 Nov. Pair 2 B on 6 Nov, A on 7 Nov. Pair 3 A on 8 Nov, B on 9 Nov.
  - **Sequencing:** on experiment days, the 13:00 reel must be a different kind and a non-#11 hook, so neither rule breaks.
  - Log `arm` (A or B) and `pair` (1, 2, 3) as columns.
- **Judge at 72 hours, in this order:**
  1. Sends per 1k reach, hand-checked to exclude Prashant
  2. Saves per 1k reach
  3. Outlier multiple against the new-niche median
  - Copy hold@3s and average watch time as diagnostics. They explain the result; they don't decide it.
- **Reading the result:**
  - Sends decide each pair. If both arms have 0 sends, saves decide. If both are also 0, the pair is a tie.
  - An arm wins if it takes at least 2 of the 3 pairs.
  - If a reel has under 20 reach at 24 hours, check it for a publishing fault. A confirmed fault voids the pair; it is not a loss.
  - Never fall back to views.
  - With 3 pairs this is directional only. If A wins, make the named-viewer opener the default next week and repeat the test before calling it a rule.
