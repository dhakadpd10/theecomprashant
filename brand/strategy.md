## The experiment: the backfire opening against the straight money opening
- **Question:** does opening on a mistake the viewer already makes (#2 backfire) earn more sends than opening straight on the money outcome (#3 Nobody Tells You)?
- **Setup:**
  - Use 6 reels in 3 matched pairs: one pair each in sites, skills and prompt.
  - Each pair has the same kind, the same keyword and a similar topic. Only the opening line and the first card differ. The scene, screenshot card, catch, send line and end card stay identical.
  - Arm A uses #2 with a rupee figure in the first second and one real message or screen shown backfiring ("₹0 from 40 applications? Stop sending this.").
  - Arm B uses #3 with the money outcome in the first second.
  - Post all 6 at 19:30 IST (14:00 UTC). Post each pair within 2 days of each other so post age stays close.
  - Log the `arm` column (A or B) on each. It has never been logged, and an unlogged arm means the test didn't run.
- **Judge at 72 hours, in this order:**
  1. Sends per 1k reach
  2. Hold@3s, copied from in-app insights
  3. Outlier multiple against 120
- **Reading the result:**
  - An arm wins if it takes at least 2 of the 3 pairs on sends.
  - If sends are 0 on both arms, judge on hold@3s.
  - If hold@3s wasn't copied, the experiment is void. Don't fall back to views.
  - With 3 pairs this is directional only. Repeat it next week before making it a rule.
